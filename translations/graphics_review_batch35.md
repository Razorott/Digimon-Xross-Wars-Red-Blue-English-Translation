# Graphics review: batch 35

The original sprites use `キャンセル` (Cancel) in one verified X-button badge and `ぼうけんかいし!` (the adventure begins) in three callout states. Batch 35 replaces these with **Cancel** and **Let's Begin!** across all four states.

The Cancel edit keeps the X icon, button border, and native 48×16 layout. The callout keeps its native 64×16 canvas and red lettering with a light outline; a dark one-pixel shadow improves separation from the scene. The shorter English phrase is chosen to keep the graphic readable at native DS resolution.

The same sprite archive has other unrelated labels in separate states, so those were not changed. This batch adds graphic states only. It does not change the translated message-slot count or the story/status-tab lettering from batch 34.
